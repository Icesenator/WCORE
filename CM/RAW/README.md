Preuves brutes **durables** du sous-projet `WCORE/CM` : sorties de commandes, réponses HTTP capturées,
diffs, preuves de tests/guards, forensics X.

- Règle Karpathy : **RAW d'abord** (`CM_RAW_FIRST=TRUE`), distillation **après** vers `Wiki/CM/` (vault).
- Autorité : **historique** (preuve d'un événement passé) — **jamais** source d'un statut CURRENT.
  Un statut CURRENT vit dans `CM/ROADMAP.md` + `CM/review-context.md`.
- Ne jamais dupliquer ici une décision distillée (pas de second corpus éditable à autorité égale).
- Aucun secret, aucun identifiant interne, aucun montant/adresse wallet.

Nomenclature : `YYYY-MM-DD-sujet.md`.
